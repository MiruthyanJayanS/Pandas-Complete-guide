# Pandas Complete Guide

A complete beginner-to-intermediate learning guide for the **Pandas** library in Python — originally created and delivered as a **seminar during college**. It remains a solid, quick-reference resource for understanding Pandas fundamentals.

## 📌 About

This repository contains the materials used to teach Pandas basics in a seminar format, combining a presentation deck with a hands-on Jupyter Notebook. The goal was to give a clear, practical walkthrough of Pandas — from the basics to commonly used operations — in a way that's easy to follow even for those new to the library.

It's structured to be useful both as **presentation material** (for teaching/reference) and as a **hands-on notebook** (for practicing the concepts directly).

## 🎯 Topics Covered

- Introduction to Pandas and why it's used
- Series and DataFrame basics
- Reading/writing data (CSV, Excel, etc.)
- Indexing, selecting, and filtering data
- Handling missing data
- GroupBy operations and aggregations
- Basic data cleaning and transformation

> Exact topics covered are detailed in the presentation and notebook within this repo.

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook or JupyterLab
- Pandas (`pip install pandas`)

### Setup
```bash
git clone https://github.com/MiruthyanJayanS/Pandas-Complete-guide.git
cd Pandas-Complete-guide
pip install pandas jupyter
```

### Usage
- Open the `.ppt`/`.pptx` file for the conceptual walkthrough (seminar slides)
- Open the `.ipynb` file in Jupyter Notebook to run the code examples hands-on:
```bash
jupyter notebook
```
